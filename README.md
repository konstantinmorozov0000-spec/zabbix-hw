Репозиторий домашних заданий по курсу «Системный администратор» (Нетология)

В этом репозитории находятся решения домашних заданий по модулям Zabbix.

Каждое задание расположено в отдельной ветке:

- zabbix-hw-1 — Установка и настройка Zabbix Server  
- zabbix-hw-2 — Установка Zabbix Agent и сбор данных  

Основная ветка (main) используется как шаблон и не содержит файлов заданий.
